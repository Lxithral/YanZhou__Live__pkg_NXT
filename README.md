# 烟洲直播包装

本地 Node.js 服务提供控制面板与 OBS 透明浏览器来源。控制台在浏览器里调整包装内容，OBS 里的输出页实时同步；不使用 obs-websocket。

当前包含五个包装模块：

- **Logo 挂角**：校徽与主副标题，校徽可单独显示/隐藏；校徽显示且两行文字齐全时，文字块上下边缘对齐校徽上下边缘
- **人物信息条**：人物资料库与 1–4 个独立槽位分开管理。每槽可选人、切换、显隐、选择 H/G/I 样式和配色，输出姓名与头衔，右半槽位镜像。三种样式：H · 烟洲新闻（深蓝标签 + 白底）、G · 烟洲校色（绛红标签 + 暖白底双线）、I · 烟洲印记（绛红细边 + 校徽水印）。
- **节目单**：维护编号、类型、标题、表演者、简介与可选封面地址，支持上一项、下一项和任意快选，OBS 以「票根 · 艺术节」节目卡显示当前节目的完整资料和下一项标题（见下文「节目卡片」）。
- **歌词字幕**：用时间轴或手动列推送，语音识别用于校准时间轴进度。
- **主持人语音字幕**：在主控台内选择音源、启动 Qwen 实时转写、清屏和调整字幕外观，停顿后自动清空。

每个模块都可以独立显示/隐藏、整体缩放、调整透明度、移动到画布任意位置，并单独设置出场与退场动画（无、淡入淡出、上浮、下沉、左滑、右滑、缩放）和动画时长（200–2000 ms）。

## 启动与 OBS 接入

1. Windows 双击 `start.cmd`；也可使用 Node.js 22 以上版本，在项目目录运行 `npm ci`（首次）和 `npm start`。保留启动窗口。
2. 浏览器打开 `http://localhost:3000/control.html`。
3. 在 OBS 添加「浏览器」来源，URL 填 `http://localhost:3000/overlay.html`，宽度 1920、高度 1080。
4. 浏览器来源自定义帧率设为 60；为保持实时控制，关闭「不可见时关闭来源」与「场景激活时刷新浏览器」。OBS 输出帧率也建议设为 60。

包装页面本身完全透明，控制面板的背景与安全区不会进入 OBS 输出。两个页面都从同一个服务取得状态；页面刷新与重连会重新取得最新设置。

## 控制面板

在「模块」栏切换 Logo 挂角、人物信息条、节目单、歌词字幕和主持人语音字幕。每张模块卡片都可直接显示或隐藏该模块。窄屏上模块栏排列在预览上方。模块设置分为四段：

- **01 显示内容**：Logo 主副标题与校徽显隐；人物信息条和节目单在这里显示人物库、槽位与节目库管理区（见「人物与节目管理」）。
- **02 外观**：文字颜色（内置取色器，支持 HEX）、Logo 字重（MiSans 可变字体 150–700）、整体大小、透明度。挂角校徽用原图颜色；人物信息条仍可自定义强调色。节目卡使用固定的烟洲校色。
- **03 位置**：水平 X / 垂直 Y 滑条与像素输入，也可直接拖动预览中的模块，或用方向键微调（按住 Shift 每次 10 px），并支持四角快捷定位。滑条范围会随模块实际尺寸调整，不会移出画面。拖动时预览只移动被拖的模块，约每秒 30 次同步到 OBS，松手后才写入设置文件。
- **04 出场 / 退场**：分别选择出场与退场动画以及动画时长。模块设置标题右侧的「出场 / 退场」可直接打开这一节。

控制台与 OBS 输出页在直播机本机实时同步，面板显示自动保存状态。主题自动跟随系统深色或浅色模式，监看背景可以单独切换，不影响 OBS 输出。预览默认使用中性灰棋盘格，配合安全区参考线观察浅色字幕、深色图文与组件位置；工具栏可切换实色灰底、浅色底或棋盘格，主画面和局部放大预览同步切换，选择会保存在当前浏览器中。

侧栏模块卡片的「上屏」状态用蓝色标出。顶部「歌词台」在同一标签页内切换，只有「打开输出页」会新开标签页。

`docs/screenshots/control-panel-v2.png` 与 `docs/screenshots/overlay-modules.png` 是当前版本的界面与输出示例。同目录其余 `.jpg` 为早期版本截图，仅供参考。

## 直播歌词台

点击主控台顶部的「歌词台」，或访问 `http://localhost:3000/lyrics.html`。主控台调整歌词外观、位置与动画，歌词台负责现场内容和输出源。

两页共享跟随系统、浅色和深色主题偏好。OBS 和主控台预览只显示当前一句歌词，整句一次点亮，不做逐字填充。带中英对照的 LRC 会合成一句：主行照常显示，译文以小一号字号排在下方；没有译文的句子只占一行。位置、缩放与出入场效果可在主控台调整。

导入 LRC 时可从 `[ti:]` 和 `[ar:]` 读取歌名和歌手，也可手动填写。点击「保存并载入」后，歌词台顶部显示当前歌曲信息。每首歌曲存为配置文件所在目录下 `config/lyrics/` 中的独立 JSON，可在左列曲库再次载入。同名歌曲默认另存为新版本，也可在导入预览中明确选择要替换的版本。旧设置中的歌词首次启动时自动收进曲库，原设置备份在项目根的 `settings.json.pre-library.bak`（历史备份已归档到 `backups/`）。

在主控台的「歌词字幕」模块可查看当前歌词进度，并用上下箭头调整曲库播放顺序。当前歌词剩余 15 秒时，歌词台平滑展开第四列，可查看下一首歌词并手动载入。

- **时间轴**可粘贴或导入 UTF-8 LRC。校对后保留的相邻两行如果时间相同且只有一行含汉字，会合成主行和译文。三行及以上共用一个时间戳时，预览会提示重复。`[offset:+500]` 将整首歌词的行和字时间提前 500 毫秒，负值延后。可在导入时填写歌曲结束时间，留空时读取 `[length:分:秒]`。两处都没有给出结束时间时，普通 LRC 依据近期换行间隔和末句长度估算停留时间。载入后点击「推送时间轴」，根据独立播放的现场伴奏起表，可点歌词跳转或用 ±0.5 秒微调。
- **手动**列显示自己选中的句子，导入歌曲后使用同一份歌词原文。可以逐行切换，也可以选择 5 秒或 10 秒后点「开始自动切句」。到最后一句或清屏时停止自动切句。聚焦热键操作区后，Enter、→ 或空格切下一句，← 切上一句，Esc 清屏。
- **时间轴纠偏**用采集结果匹配已经载入的歌词，校准 A 列进度。歌词可从时间轴或手动列推送。

### 百炼实时识别配置

主持人字幕和歌词纠偏轮流使用一路百炼实时识别，只需联网和北京区 API Key。可选择「千问 3 实时」或「千问音频 3.0 流式」，也可选「自定义模型 ID」直接填百炼型号：型号名里带 streaming 的走流式任务接口，其余走实时会话接口。两个字幕模块共用一个 OBS 输出地址。不需要本地模型、WSL 或 Python。

1. 在 [阿里云百炼](https://bailian.console.aliyun.com/) 的华北 2（北京）业务空间创建 API Key。
2. 双击 `start.cmd`，在主控台选择「主持人语音字幕」，展开「API Key」，填写北京区百炼 API Key。如使用业务空间专属域名，再填写同一空间的业务空间 ID（通常以 `llm-` 开头）；否则可留空。点击「保存 API Key」后，配置写入本机 `.env`，立即用于当前服务，歌词台也共用这份配置。正在采集或测试连接时，先停止并等待完成再保存。
3. 在主控台或歌词台点击「测试连接」。测试只验证会话配置，不传音频。通过后选音源；主持人字幕点「启动识别」，歌词纠偏点「启动采集」。

仍支持手工配置：把项目根目录的 `.env.example` 复制为 `.env`，填写 `DASHSCOPE_API_KEY` 和可选的 `DASHSCOPE_WORKSPACE_ID`，再启动服务。Windows 可在项目目录执行 `copy .env.example .env`（CMD），再用记事本打开 `.env`。服务启动时，同名环境变量优先于 `.env`；主控台保存后立即使用新配置。

在主控台选择「千问音频 3.0 流式」后，可在「临时热词」填写本次活动的校名、人名和节目名。一行一个，也可用逗号分隔，最多 50 项。首次使用会预填校名和总台名称。需要本届主持人姓名或节目名时，可点击「补入 2026 活动词表」。模型选择由同一浏览器的两页各自保存：主持人字幕默认「千问音频 3.0 流式」，歌词纠偏默认「千问 3 实时」，在哪一页切换只影响该页。词表只用于主持人字幕，下次启动时发送。要调整词表，请先停止采集，再编辑并启动。[流式模型热词参数](https://help.aliyun.com/zh/model-studio/qwen-audio-asr-streaming-client-events)

页面不会回显已保存的密钥，密钥也不会进入 `settings.json` 或浏览器 `localStorage`；填写新 Key 可替换旧值。不要把本机 `.env` 放进共享的部署包。启动识别后，音频会传给百炼，按送入的音频时长计费；项目不会把识别音频或临时转写存到磁盘。无密钥或云端不可用时，仍可正常使用节目单和歌词手动／时间轴。旧项目目录里的 `.asr-models/`、`.venv-qwen-asr/` 可移除，原设置和曲库可直接沿用。[实时接口](https://help.aliyun.com/zh/model-studio/qwen-asr-realtime-interaction-process) · [百炼定价](https://help.aliyun.com/zh/model-studio/model-pricing)

### 主持人语音字幕

在现有主控台的「模块」栏选择「主持人语音字幕」，直接选择麦克风、VB-CABLE 或浏览器标签页音源，点击「启动识别」，打开该模块显示开关即可上屏；无需新控制页或新的 OBS 来源。输入设备以平铺列表列出，每台设备带一条实时电平条，说话时哪条在跳就选哪台；列表第一次出现时浏览器会请求麦克风权限，被拒绝时列表下方会给出放行步骤。歌词台的输入设备使用同一套列表。可在同一处停止采集、清屏，以及调整字幕颜色、位置、大小和出入场动画。识别文本采用纯文本呈现，长句显示末尾最多 120 字并自动缩放换行。字幕不会因停顿自动消失：保留最后一句，直到点「清屏」、断开音源或退出采集页面；刷新 OBS 会重新取得当前字幕，重启 Node 不恢复主持人旧话语。

同一时间只开启一路采集。主控台采集供主持人字幕，歌词台采集供时间轴纠偏。切换用途时先停止，再到对应页面选择音源。

API Key、识别模型、临时热词、音源和字幕行为可分别折叠，启动识别、停止采集、测试连接与清屏等常用操作保持可见。

### 歌词时间轴纠偏

歌词台 C 列选音源并启动采集。A 列推送时间轴并开始播放后，勾选「时间轴自动纠偏」。C 列根据匹配结果调整进度，画面显示导入的歌词。「匹配参考」中的转写仅用于核对。

百炼会边听边返回草稿，并在停顿后定稿。纠偏根据定稿对应的音频位置估算，界面标记「时间估算」。过时或缺少有效语音结束位置的结果会跳过纠偏。请用现场伴奏和人声彩排，间奏、重复歌词或网络抖动会影响效果。

断网、额度不足或积压时，停止采集并清空主持人字幕，可手动重新启动。已推送的歌词时间轴或手动字幕照常工作。

C 列显示偏移、对齐置信度和修正记录。低置信度或无法区分的重复歌词会被跳过。

刷新页面会恢复当前会话。OBS 短时断线时，时间轴以最后收到的速率走到文档末尾，手动字幕保留最后一条画面。输出源随设置一起保存：Node 服务重启后自动恢复上次推送的时间轴或手动字幕（进度照常恢复、时间轴暂停在原位置，画面直接续上，无需再点一次推送）；推送中若已手动切到「待推送」，重启后保持停止。语音识别依赖浏览器采集，重启后需重新启动采集。配置第一次补齐歌词模块时会生成 `settings.json.pre-lyrics.bak`。切回旧版服务时同步恢复原配置。

现场彩排时，先用独立 OBS 场景确认五个模块的实际位置与可见状态，再按现场音源测试歌词走表和纠偏。

## 设置保存

设置记录在项目根目录的 `settings.json`。画面实时更新，连续拖动与输入会在停止约 120 ms 后合并写入磁盘。面板显示「已保存」时，文件已写入。正常退出会保存最后的修改。

如要手动编辑 `settings.json`，先正常退出服务再修改；启动时发现文件损坏会报错并保留原文件。

曲库 `config/lyrics/` 随仓库一起提交，换电脑拉下来就是同一批歌。如果设置里记录的当前歌曲在曲库里找不到，服务照常启动，终端提示「曲库中找不到歌曲（编号 …），已跳过，请在歌词台重新选择或导入。」，主控台和歌词台顶部也会出现同样的提示条，可手动关闭；`settings.json` 不会因此被改写。

旧版设置会在启动时自动迁移并写回：`version: 1`（只有 Logo 挂角）迁移为模块结构，`version: 2` 补充 Logo 校徽显隐（`showMark`），`version: 3` 补充 Logo 字重（`weight`，可变字体 150–700），原有内容、颜色与位置都会保留。

## 设置结构

```json
{
  "version": 5,
  "canvas": { "width": 1920, "height": 1080 },
  "modules": {
    "logo": {
      "visible": true, "showMark": true, "title": "中山市烟洲中学", "subtitle": "YANZHOU · LIVE",
      "color": "#FFFFFF", "textColor": "#772B2C", "weight": 500,
      "x": 112, "y": 70, "scale": 1, "opacity": 100,
      "animation": { "enter": "fade-up", "exit": "fade-down", "duration": 600 }
    },
    "hosts": { "visible": false, "label": "主持人", "names": "张三\n李四", "style": "h", "slotCount": 2, "accentColor": "#71C4DE", "textColor": "#2C2C2E", "people": ["..."], "slots": ["..."], "...": "..." },
    "program": { "visible": false, "label": "正在演出", "current": "开场舞", "nextLabel": "接下来", "next": "合唱", "x": 1280, "y": 770, "items": [{ "id": "program-1", "number": "01", "type": "舞蹈", "title": "开场舞", "performer": "高二2班 …", "desc": "…", "cover": "" }], "selectedId": "program-1", "...": "..." }
  }

```

可选的 `"layout": { "autoAvoid": false }` 记录「自动避让」开关；没有这一项时视为开启。

颜色使用六位 HEX；坐标范围 0–1920 / 0–1080，整体大小 25–300%，透明度 0–100%，动画时长 200–2000 ms。

## 文件结构

```
server/               服务端（Node，无构建步骤）
  server.js             静态文件、/api/state、/health、WebSocket /ws
  stage-management.js   人物库、槽位与节目库的事件与校验
  lyrics-session.js     歌词会话、时间轴与手动/识别推送
  lyrics-library.js     曲库读写（config/lyrics/*.json）
  asr-capture.js        百炼实时识别连接与单路采集
  asr-match.js          识别结果与歌词的匹配纠偏
  speech-session.js     主持人字幕的寿命管理
public/               前端（浏览器直接加载，无打包）
  control.html          控制面板
  lyrics.html           直播歌词台
  overlay.html          OBS 输出页
  css/                  control / lyrics / overlay / host-appearance / school-watermark
  js/
    control.js          控制面板入口
    lyrics.js           歌词台入口
    overlay.js          输出页入口
    core/               主题、模块层级（定位/缩放/透明度/动画）、自定义下拉
    render/             五个模块的渲染器与人物条外观
    lyrics/             LRC 解析、文档校验、客户端时钟
    asr/                识别控制条、识别参数、设备电平表、音频 worklet
    stage/              主控台管理区、自动避让计算
    motion/             节目卡演出者与介绍的滚动参数
config/               默认人物库、默认节目库、歌词曲库 config/lyrics/
assets/               字体与素材；A12.png 为挂角校徽，yanzhou-watermark.png 为人物条和节目卡共用的校徽水印
test/                 node --test 测试（服务、歌词、识别、避让、滚动、节目顺序）
tools/                start.cmd 用的启动脚本，以及界面检查脚本（需本地 Chrome）
docs/screenshots/     界面与输出截图
backups/              首次启用各功能时自动生成的旧设置备份（不入库）
```

静态服务把 `/xxx` 直接映射到 `public/xxx`、`/assets/xxx` 映射到 `assets/xxx`，所以上述目录只是文件组织方式，URL 与目录层级一一对应。

- `public/js/core/module-layer.js`：所有模块共用的定位、缩放、透明度与动画层。
- `public/js/render/`：五个模块的渲染器；`speech-renderer.js` 为主持人语音字幕，`program-renderer.js` 为票根节目卡（含长标题缩字），`host-appearance.js` 与 `public/css/host-appearance.css`、`school-watermark.css` 为人物信息条 H/G/I 三种样式。
- `public/js/lyrics/lyrics-model.js`：LRC 格式与文档校验；`lyrics-clock.js` 为客户端时钟。
- `public/js/stage/stage-avoidance.js`：自动避让（输出页和主控台预览共用同一套计算）。
- `config/people-defaults.json` / `program-defaults.json`：首次启用时载入的默认资料。

## 开发与检查

首次安装依赖：`npm install --no-audit --no-fund`。测试：`npm test`。

默认只监听本机 `127.0.0.1:3000`。如端口已有其他程序使用，可设置环境变量 `PORT` 为其他端口，并同步修改浏览器及 OBS 地址。服务不使用数据库或云端服务。OBS 中的实际出画延迟尚未做端到端实测。

## 人物与节目管理

在主控台相应模块的「显示内容」区管理人物库、槽位与节目库。标题行显示数量、上屏状态和连接状态。节目可以用当前节目卡左右按钮或「快速切换」网格切换，资料在「节目资料库」编辑。每条人物字幕有单独的显隐、换人和 H/G/I 样式操作。「选择人物」打开各槽共用的搜索窗口，可按姓名或班级查询。所有已启用的槽位都隐藏或空置时，人物模块显示「未显示」。自定义颜色收在「自定义颜色」里。资料库支持新增和编辑，服务端写盘成功后会同步更新，断线时编辑草稿保留。

首次启用时，现有配置备份到 `settings.json.pre-management.bak`（历史备份已归档到 `backups/`），并载入默认人物库中的四位主持人和默认节目库中的十三项节目（含嘉宾节目与互动游戏）。首次初始化后，删除至空列表也会持久保存。人物与节目使用稳定编号，删除前面的条目不会改变其他槽位或当前节目的人选。删除被使用的人物会清空并隐藏相关槽位，删除当前节目则选后继，已无后继时选前一项。

**调整节目顺序**：在「节目资料库」点「解锁排序」，拖动六点手柄，或聚焦手柄后按 ↑ ↓ 移动一位。可用「撤销排序」恢复本次连接内最近一次移动前的顺序。每次排序和撤销都会保存到 `settings.json` 并同步给其他主控台，按新顺序生成编号，且保持当前节目。准备切播时可点「锁定排序」，从「快速切换」网格选节目。

人物热键区的 0 切整体显隐，1–4 切对应已启用槽位；节目热键区的左右方向键切节目，0 切显隐。热键需要先点一下对应的热键提示条（聚焦后提示条变蓝并显示「已启用」）。四槽选择、样式与配色在减少启用数量后保留。位置、缩放、透明度和出入场动画作用于整组人物条。

资料保存在 settings.json 的 modules.hosts.people、slots 和 modules.program.items、selectedId 中。通过同一 /ws 的 hosts:manage 与 program:manage 命令操作，沿用关联 ID 和错误回执，成功返回 management:result。单库最多 200 项、80 KiB，普通指令维持 16 KiB 限制。

## 节目卡片（票根 · 艺术节）

节目单在 OBS 中显示为一张演出票：左侧绛红主票排内容，右侧米色存根放序号和校徽，中间是齿孔撕票线，上下两个半圆缺口透出舞台画面。卡片宽 510 px（大小 100% 时；相当于旧版的 75%，旧设置里存的 100% 现在显示为旧版 75% 的大小）。高度随内容变化：介绍满 3 行、演出者 1 行、有「接下来」时约 264 px，演出者 2 行时约 287 px；介绍不足 3 行或演出者、「接下来」为空时相应变矮。介绍右侧的竖条放在卡片原有的右侧留白里，不占介绍的宽度，也不增加高度。卡片只使用本地字体（MiSans / 微软雅黑）和 `assets/yanzhou-watermark.png`，不需联网。

卡片内容来自节目库中当前选中的节目：

- **标签**（如「正在演出」）与 **类型**：顶部两枚小标签；标签文字来自设置中的 `label`（默认「正在演出」），「接下来」文字来自 `nextLabel`。
- **标题**：大字节目名。过长时先逐步缩小字号（37.5 px 起，最小 25.5 px，均为大小 100% 时），仍放不下再显示省略号。
- **演出者**：「表演者」区域最多显示 2 行。放得下就静止显示；放不下时在这 2 行里**竖向无缝循环滚动**：内容复制一份接在后面，速度 24 px/秒，上下边缘 5 px 渐隐，两轮之间留约一行空白。
- **介绍**：最多显示 3 行。放得下就静止显示；放不下时在这 3 行里**竖向慢慢向上滚动**，速度按每秒 3.5 个汉字的阅读速度换算：每行字数 = 可视宽 ÷ 字宽（大小 100% 时 350 ÷ 14.25 ≈ 24.6 字），读完一行约 7 秒，所以每秒上移 行高 23.5 px ÷ 7.02 秒 ≈ 3.35 px。上下边缘渐隐。滚到文末停 2.5 秒，淡出回到开头，再停 1.5 秒后开始下一轮。介绍右侧有一条细竖条（宽 2 px，和 3 行可视区等高，离文字约 9 px），只在滚动时显示：竖条里亮的那段长短表示可见部分占全文的比例（可视高度 ÷ 全文高度，最短 12%，越短说明介绍越长），位置跟着滚动进度从上走到下，表示读到了哪里；淡出回到开头时也一起回到顶部。
- **序号**：显示在存根上（「节目 + 序号 + 校徽」）；没有序号时（如嘉宾节目）存根只显示放大的校徽。
- **接下来**：取节目库中的下一项标题；已是最后一项时这一行隐藏，卡片自动变短。

**滚动规则**：只有放不下时才滚动。卡片上屏后，先等入场动画放完，再停 1.5 秒开始滚动；之后只要卡片在屏上就一直循环。切换节目或内容改变时从头开始；调整大小、拖动位置不会打断；卡片下屏、退场动画放完后停止。主控台预览与 OBS 输出效果一致。

滚动速度依据：中文字幕规范（Netflix 简体中文成人上限每秒 9 字、儿童 7 字）与眼动研究（成人中文句子阅读约每秒 4.3 字）；滚动文字比静止文字更难读，因此介绍取舒适偏慢的每秒 3.5 字，再按每行字数和行高换算成上滚速度。

**参数位置**（改完刷新主控台和 OBS 浏览器源即可）：

- 演出者滚动：`public/js/motion/perf-scroll.js` 的 `PERF_SCROLL`——`speed`（像素/秒，默认 24）、`pause`（开始前停顿毫秒，默认 1500）、`gap`（两轮之间空白，默认 22 px）、`fade`（渐隐，默认 5 px）、`lines`（可视行数，默认 2）。
- 介绍滚动：`public/js/motion/intro-scroll.js` 的 `INTRO_SCROLL`——`charsPerSecond`（阅读速度，每秒字数，默认 3.5）、`fontSize`（介绍字号，默认 14.25）、`lineHeight`（行高倍数，默认 1.65）、`lines`（可视行数，默认 3）、`pause`（开始前停顿，默认 1500）、`holdEnd`（文末停留，默认 2500）、`fadeOut` / `fadeIn`（淡出淡入，默认各 300）、`holdStart`（回到开头后停留，默认 1500）、`fade`（上下渐隐，默认 5 px）、`minThumb`（竖条亮段最短比例，默认 0.12）。

类型、演出者或介绍留空时对应一行不显示。旧设置没有节目库时，卡片退回显示 `current` / `next` 两个文字。

节目上屏后，在主控台「节目单 · 局部放大」旁点「撕开票根」，米色存根会沿齿孔拉开，主票位置保持不变。点「恢复票根」可合回去，再次撕开。切节目或再次上屏时默认完整。两种状态同步到 OBS 和预览，刷新页面不会重播，服务重启后恢复完整。

新装时，校徽挂角默认在左上方（**X 112、Y 70**），节目卡默认在右下方（**X 1280、Y 770**）。在 1920 × 1080 画布上，100% 大小的节目卡右沿距安全线 34 px。可以在主控台预览中拖动模块调整位置。

## 自动避让



- 让开时选移动距离最小、不出画面、并与其他模块留出 16 px 间距的位置：先试上下移动，放不下再左右移动，最后才斜向移动。
- 人物信息条例外：**不管谁先出现，都由人物信息条让开**，其他模块不动。它不会上下跳，而是保持在原来那一行，整组往没有障碍的一侧平移（障碍在右就往左靠，在左就往右靠），两条之间的距离保持不变，并和障碍留 96 px。整组平移会越过画面安全区（左右各 96 px，即预览里的虚线框）时，外侧那条停在安全区边上，再缩小两条之间的距离（至少 24 px）；还放不下，就把和障碍的距离逐步减到 48 px。这一行实在放不下时，才退回「后出现的让开」。
- 挡住人物信息条的模块关闭后，要等它的退场动画完全放完（时长按该模块的动画设置），人物信息条才滑回原来左右对称的位置；淡出途中重新打开，则保持靠拢不动。
- 避让只是画面上的临时偏移，不改写保存的位置。冲突消失（比如先出现的模块隐藏了）后，模块自动滑回原位，人物信息条恢复原来左右对称的样子。
- 尺寸按实际画面量取（节目卡高度随内容变化）。输出页与主控台预览用同一套计算，结果一致；移动时有约 0.35 秒的缓动，刚出现的模块直接出现在让开后的位置。
- 在主控台预览里拖动时，各模块保持当前位置不跳动，松手后再重新计算；OBS 输出在拖动过程中就会实时避让。
- 预览工具栏的「自动避让」可随时关闭，开关状态保存在 `settings.json` 的 `layout.autoAvoid`。
