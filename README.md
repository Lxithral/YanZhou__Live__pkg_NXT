# 烟洲直播包装

本地 Node.js 服务提供控制面板与 OBS 透明浏览器来源。控制台在浏览器里调整包装内容，OBS 里的输出页实时同步；不使用 obs-websocket。

当前包含四个包装模块：

- **Logo 挂角**：校徽与主副标题，校徽可单独显示/隐藏；校徽显示且两行文字齐全时，文字块上下边缘对齐校徽上下边缘
- **人物信息条**：人物资料库与 1–4 个独立槽位分开管理。每槽可选人、切换、显隐、选择 H/G/I 样式和配色，输出姓名与头衔，右半槽位镜像。三种样式：H · 烟洲新闻（深蓝标签 + 白底）、G · 烟洲校色（绛红标签 + 暖白底双线）、I · 烟洲印记（绛红细边 + 校徽水印）。
- **节目单**：维护编号、类型、标题、表演者、简介与可选封面地址，支持上一项、下一项和任意快选，OBS 以「票根 · 艺术节」节目卡显示当前节目的完整资料和下一项标题（见下文「节目卡片」）。
- **歌词字幕**：时间轴、手动和离线识别共用同一个单行 OBS 字幕。

每个模块都可以独立显示/隐藏、整体缩放、调整透明度、移动到画布任意位置，并单独设置出场与退场动画（无、淡入淡出、上浮、下沉、左滑、右滑、缩放）和动画时长（200–2000 ms）。

## 启动与 OBS 接入

1. 双击 `start.cmd`，或者在项目目录运行 `npm start`。保留服务窗口。
2. 浏览器打开 `http://localhost:3000/control.html`。
3. 在 OBS 添加「浏览器」来源，URL 填 `http://localhost:3000/overlay.html`，宽度 1920、高度 1080。
4. 浏览器来源自定义帧率设为 60；为保持实时控制，关闭「不可见时关闭来源」与「场景激活时刷新浏览器」。OBS 输出帧率也建议设为 60。

包装页面本身完全透明，控制面板的背景与安全区不会进入 OBS 输出。两个页面都从同一个服务取得状态；页面刷新与重连会重新取得最新设置。

## 控制面板

在「模块」栏切换 Logo 挂角、人物信息条、节目单和歌词字幕。每张模块卡片都可直接显示或隐藏该模块。窄屏上模块栏排列在预览上方。模块设置分为四段：

- **01 显示内容**：Logo 主副标题与校徽显隐；人物信息条和节目单在这里显示人物库、槽位与节目库管理区（见「人物与节目管理」）。
- **02 外观**：校徽色/强调色与文字颜色（内置取色器，支持 HEX）、Logo 字重（MiSans 可变字体 150–700）、整体大小、透明度。节目卡使用固定的烟洲校色，外观区只调整整体大小和透明度。
- **03 位置**：水平 X / 垂直 Y 滑条与像素输入，也可直接拖动预览中的模块，或用方向键微调（按住 Shift 每次 10 px），并支持四角快捷定位。滑条范围会随模块实际尺寸调整，不会移出画面。拖动时预览只移动被拖的模块，约每秒 30 次同步到 OBS，松手后才写入设置文件。
- **04 出场 / 退场**：分别选择出场与退场动画以及动画时长。

控制台与 OBS 输出页在直播机本机实时同步，面板显示自动保存状态。主题自动跟随系统深色或浅色模式，监看背景可以单独切换，不影响 OBS 输出。预览默认使用中性灰棋盘格，配合安全区参考线观察浅色字幕、深色图文与组件位置；工具栏可切换实色灰底、浅色底或棋盘格，主画面和局部放大预览同步切换，选择会保存在当前浏览器中。

侧栏模块卡片的「上屏」状态用蓝色标出。顶部「歌词台」在同一标签页内切换，只有「打开输出页」会新开标签页。

`previews/control-panel-v2.png` 与 `previews/overlay-modules.png` 是当前版本的界面与输出示例。`previews/` 中其余 `.jpg` 为早期版本截图，仅供参考。

## 直播歌词台

点击主控台顶部的「歌词台」，或访问 `http://localhost:3000/lyrics.html`。主控台调整歌词外观、位置与动画，歌词台负责现场内容和输出源。

两页共享跟随系统、浅色和深色主题偏好。OBS 和主控台预览只显示当前一句歌词。位置、缩放与出入场效果可在主控台调整。

导入 LRC 时可从 `[ti:]` 和 `[ar:]` 读取歌名和歌手，也可手动填写。点击「保存并载入」后，歌词台顶部显示当前歌曲信息。每首歌曲存为配置文件所在目录下 `config/lyrics/` 中的独立 JSON，可在左列曲库再次载入。同名歌曲默认另存为新版本，也可在导入预览中明确选择要替换的版本。旧设置中的歌词首次启动时自动收进曲库，原设置备份为 `settings.json.pre-library.bak`。

在主控台的「歌词字幕」模块可查看当前歌词进度，并用上下箭头调整曲库播放顺序。当前歌词剩余 15 秒时，歌词台平滑展开第四列，可查看下一首歌词并手动载入。

- **时间轴**可粘贴或导入 UTF-8 LRC。预览列出有效句与问题行，支持逐行编辑、跳过和删除。确认载入后点击「推送时间轴」，根据现场伴奏起表，可点歌词跳转或用 ±0.5 秒微调。伴奏由现场音源单独播放。
- **手动**列在时间轴播放时跟随当前歌曲滚动，两列的播放／暂停按钮控制同一时间轴。手动输出仍可逐行切换。聚焦热键操作区后，Enter、→ 或空格切下一句，← 切上一句，Esc 清屏。自动切句可选 5 秒或 10 秒。
- **语音识别**可独立推送确认句，也可在时间轴上屏时自动纠偏。切换输出源时，时间轴和手动列各自继续运行。

### P2 离线识别准备

在 Windows x64 直播机上安装 Node.js LTS。首次使用在项目目录执行 `npm install`、`npm run asr:setup`，然后重启服务。首次准备需要联网下载约 373 MB 模型文件。只需一种模式时可执行 `npm run asr:setup -- bilingual` 或 `npm run asr:setup -- trilingual`。模型存放在本机 `.asr-models/`，也可用 `YZ_ASR_MODELS_DIR` 指定路径。识别运行时完全离线，浏览器采集的音频不落盘。

- **识别模式**提供普通话／英语与普通话／粤语／英语。前者使用带词级时间戳的 Zipformer，后者使用三语 Paraformer，纠偏时间通过音频进度估算。
- **麦克风**可用系统默认设备或从下拉框选设备。**VB-CABLE** 请选择录音端的 `CABLE Output`，把现场音源送入 `CABLE Input`。首次选虚拟声卡时，浏览器可能需要授权以显示设备名称。**标签页音频**需在 Chrome 选择浏览器标签页并勾选共享音频，采集会随共享结束而停止。
- 点击「启动」并授权选定音源后，C 列显示临时结果和确认句。「推送识别」只将确认句送到 OBS。停止采集时，识别输出自动解除推送。
- A 列正在走表且推送到 OBS 时，可开启「时间轴自动纠偏」。C 列显示偏移、对齐置信度和修正记录。低置信度或无法区分的重复歌词会被跳过。每次彩排按本场伴奏和人声检查效果，模式切换在停止采集后生效。

刷新页面会恢复当前会话。OBS 短时断线时，时间轴以最后收到的速率走到文档末尾，手动字幕保留最后一条画面。输出源随设置一起保存：Node 服务重启后自动恢复上次推送的时间轴或手动字幕（进度照常恢复、时间轴暂停在原位置，画面直接续上，无需再点一次推送）；推送中若已手动切到「待推送」，重启后保持停止。语音识别依赖浏览器采集，重启后不会自动恢复，需重新启动采集再推送。配置第一次补齐歌词模块时会生成 `settings.json.pre-lyrics.bak`。切回旧版服务时同步恢复原配置。

现场彩排时，先用独立 OBS 场景确认四个模块的实际位置与可见状态，再按现场音源测试歌词走表和纠偏。

## 设置保存

设置记录在项目根目录的 `settings.json`。画面实时更新，连续拖动与输入会在停止约 120 ms 后合并写入磁盘。面板显示「已保存」时，文件已写入。正常退出会保存最后的修改。

如要手动编辑 `settings.json`，先正常退出服务再修改；启动时发现文件损坏会报错并保留原文件。

换电脑或重新解压时，`config/lyrics/` 曲库可能没有一起拷过来（它不进 git）。如果设置里记录的当前歌曲在曲库中找不到，服务照常启动，终端提示「曲库中找不到歌曲（编号 …），已跳过，请在歌词台重新选择或导入。」，主控台和歌词台顶部也会出现同样的提示条，可手动关闭；`settings.json` 不会因此被改写。

旧版设置会在启动时自动迁移并写回：`version: 1`（只有 Logo 挂角）迁移为模块结构，`version: 2` 补充 Logo 校徽显隐（`showMark`），`version: 3` 补充 Logo 字重（`weight`，可变字体 150–700），原有内容、颜色与位置都会保留。

## 文件结构

- `server/server.js`：静态文件、`/api/state`、`/health`、WebSocket `/ws`（Origin 校验、单模块原子 patch、广播 `state` / `saved`、15 秒心跳、退出保存）。服务端代码都在 `server/` 下。
- `public/module-layer.js`：所有模块共用的定位、缩放、透明度与动画层。
- `public/*-renderer.js`：四个模块的渲染器；`program-renderer.js` 为票根节目卡（含长标题缩字）。
- `public/host-appearance.js` / `host-appearance.css` / `school-watermark.css`：人物信息条 H/G/I 三种样式。
- `server/stage-management.js`、`public/stage-controls.js`：人物库、槽位与节目库的服务端校验和主控台管理区；`config/people-defaults.json` / `program-defaults.json` 为首次启用时载入的默认资料。
- `public/lyrics.html` / `lyrics.js` / `lyrics.css`：独立歌词台。
- `server/lyrics-session.js`、`public/lyrics-model.js` / `lyrics-clock.js`：歌词会话、LRC 格式及客户端时钟。
- `public/control.html` / `control.js` / `control.css`：控制面板。
- `public/overlay.html` / `overlay.js` / `overlay.css`：OBS 输出页。
- `public/stage-avoidance.js`：自动避让（输出页和主控台预览共用同一套计算）。
- `test/server.test.js` / `asr.test.js` / `avoidance.test.js`：包装模块、歌词、WebSocket、重连、配置迁移与识别匹配测试。
- `assets/`：字体与原始素材；`logo-mask.png` 为由原校徽派生的透明着色版本，原图没有修改；`yanzhou-watermark.png` 为人物条和节目卡共用的校徽水印。
- `config/lyrics/`：歌词曲库；`settings.json`：设置文件（均在项目根目录）。
- `tools/`：ASR 模型安装（`setup-asr.js`）与界面检查脚本；`previews/`：界面截图。

## 开发与检查

首次安装依赖：`npm install --no-audit --no-fund`。测试：`npm test`。

默认只监听本机 `127.0.0.1:3000`。如端口已有其他程序使用，可设置环境变量 `PORT` 为其他端口，并同步修改浏览器及 OBS 地址。服务不使用数据库或云端服务。OBS 中的实际出画延迟尚未做端到端实测。

## 人物与节目管理

在主控台相应模块的「显示内容」区管理人物库、槽位与节目库。管理区从上到下：标题行（数量、「画面中 / 未显示」状态、连接状态）、整宽的「显示 / 隐藏」主按钮（热键 0）、热键提示条，然后是各自的操作区。节目：当前节目与下一个节目合在一张卡里（◀ ▶ 切换），下面是四列「快速切换」网格（当前节目蓝框，下一个虚线框并标「下一个」）和「节目资料库」列表（演出者与简介在列表中最多显示两行，完整内容在编辑框里）。主持人：显示数量分段按钮、字幕条位置输入，每个字幕条一张卡，含状态（画面中 / 待上屏 / 已隐藏 / 未启用，蓝色实线 = 画面中，蓝色虚线 = 整体隐藏时待上屏）、单条显隐按钮（标出热键 1–4）、换人、人物快选和 H/G/I 样式分段按钮，自定义颜色收在「自定义颜色」里；最下面是「人物资料库」。「+ 添加主持人 / + 添加节目」在资料库标题右侧。编辑在资料卡片内展开并保留草稿，点击保存后，服务端写盘成功才同步更新上屏内容。取消编辑不更新资料。断线时草稿保留，重连后可以重试。

首次启用时，现有配置备份到 settings.json.pre-management.bak，并载入参考 res.zip 的四位人物和十六项节目。首次初始化后，删除至空列表也会持久保存。人物与节目使用稳定编号，删除前面的条目不会改变其他槽位或当前节目的人选。删除被使用的人物会清空并隐藏相关槽位，删除当前节目则选后继，已无后继时选前一项。

**调整节目顺序**：两种拖法——在「节目资料库」里按住每行左侧的六点手柄上下拖；或在「快速切换」网格里直接按住格子拖（移动超过约 6px 才算拖动，轻点仍是切换节目）。拖动时蓝色细线标出放下的位置。也可以先选中（Tab 聚焦）六点手柄，再按 ↑ ↓ 一次移动一位。松手后新顺序立即写入 settings.json 并同步到所有打开的主控台；当前节目保持不变，◀ ▶、← →、「下一个节目」和节目卡上的「接下来」都按新顺序走。**拖动排序后所有节目的编号会按新顺序自动重排为 01、02、03……**（超过 99 个节目时为三位），节目卡上的编号随之更新；单独编辑或新增节目不会改动其他节目的编号。正在保存或有节目处于编辑状态时暂时不能拖动。

人物热键区的 0 切整体显隐，1–4 切对应已启用槽位；节目热键区的左右方向键切节目，0 切显隐。热键需要先点一下对应的热键提示条（聚焦后提示条变蓝并显示「已启用」）。四槽选择、样式与配色在减少启用数量后保留。位置、缩放、透明度和出入场动画作用于整组人物条。

资料保存在 settings.json 的 modules.hosts.people、slots 和 modules.program.items、selectedId 中。通过同一 /ws 的 hosts:manage 与 program:manage 命令操作，沿用关联 ID 和错误回执，成功返回 management:result。单库最多 200 项、80 KiB，普通指令维持 16 KiB 限制。

## 节目卡片（票根 · 艺术节）

节目单在 OBS 中显示为一张演出票：左侧绛红主票排内容，右侧米色存根放序号和校徽，中间是齿孔撕票线，上下两个半圆缺口透出舞台画面。卡片宽 510 px（大小 100% 时；相当于旧版的 75%，旧设置里存的 100% 现在显示为旧版 75% 的大小）。高度随内容变化：介绍满 3 行、演出者 1 行、有「接下来」时约 264 px，演出者 2 行时约 287 px；介绍不足 3 行或演出者、「接下来」为空时相应变矮。介绍右侧的竖条放在卡片原有的右侧留白里，不占介绍的宽度，也不增加高度。卡片只使用本地字体（MiSans / 微软雅黑）和 `assets/yanzhou-watermark.png`，不需联网。

卡片内容来自节目库中当前选中的节目：

- **标签**（如「正在演出」）与 **类型**：顶部两枚小标签；标签文字来自设置中的 `label`（默认「正在演出」），「接下来」文字来自 `nextLabel`。
- **标题**：大字节目名。过长时先逐步缩小字号（37.5 px 起，最小 25.5 px，均为大小 100% 时），仍放不下再显示省略号。
- **演出者**：「表演者」区域最多显示 2 行。放得下就静止显示；放不下时在这 2 行里**竖向无缝循环滚动**：内容复制一份接在后面，速度 24 px/秒，上下边缘 5 px 渐隐，两轮之间留约一行空白。
- **介绍**：最多显示 3 行。放得下就静止显示；放不下时在这 3 行里**竖向慢慢向上滚动**，速度按每秒 3.5 个汉字的阅读速度换算：每行字数 = 可视宽 ÷ 字宽（大小 100% 时 350 ÷ 14.25 ≈ 24.6 字），读完一行约 7 秒，所以每秒上移 行高 23.5 px ÷ 7.02 秒 ≈ 3.35 px。上下边缘渐隐。滚到文末停 2.5 秒，淡出回到开头，再停 1.5 秒后开始下一轮。介绍右侧有一条细竖条（宽 2 px，和 3 行可视区等高，离文字约 9 px），只在滚动时显示：竖条里亮的那段长短表示可见部分占全文的比例（可视高度 ÷ 全文高度，最短 12%，越短说明介绍越长），位置跟着滚动进度从上走到下，表示读到了哪里；淡出回到开头时也一起回到顶部。
- **序号**：显示在存根上（「节目 + 序号 + 校徽」）；没有序号时（如嘉宾节目）存根只显示放大的校徽。
- **接下来**：取节目库中的下一项标题；已是最后一项时这一行隐藏，卡片自动变短。

**滚动规则**：只有放不下时才滚动。卡片上屏后，先等入场动画放完，再停 1.5 秒开始滚动；之后只要卡片在屏上就一直循环。切换节目或内容改变时从头开始；调整大小、拖动位置不会打断；卡片下屏、退场动画放完后停止。主控台预览与 OBS 输出效果一致。

滚动速度依据：中文字幕规范（Netflix 简体中文成人上限每秒 9 字、儿童 7 字）与眼动研究（成人中文句子阅读约每秒 4.3 字）；滚动文字比静止文字更难读，因此介绍取舒适偏慢的每秒 3.5 字，再按每行字数和行高换算成上滚速度。

**参数位置**（改完刷新主控台和 OBS 浏览器源即可）：

- 演出者滚动：`public/perf-scroll.js` 的 `PERF_SCROLL`——`speed`（像素/秒，默认 24）、`pause`（开始前停顿毫秒，默认 1500）、`gap`（两轮之间空白，默认 22 px）、`fade`（渐隐，默认 5 px）、`lines`（可视行数，默认 2）。
- 介绍滚动：`public/intro-scroll.js` 的 `INTRO_SCROLL`——`charsPerSecond`（阅读速度，每秒字数，默认 3.5）、`fontSize`（介绍字号，默认 14.25）、`lineHeight`（行高倍数，默认 1.65）、`lines`（可视行数，默认 3）、`pause`（开始前停顿，默认 1500）、`holdEnd`（文末停留，默认 2500）、`fadeOut` / `fadeIn`（淡出淡入，默认各 300）、`holdStart`（回到开头后停留，默认 1500）、`fade`（上下渐隐，默认 5 px）、`minThumb`（竖条亮段最短比例，默认 0.12）。

类型、演出者或介绍留空时对应一行不显示。旧设置没有节目库时，卡片退回显示 `current` / `next` 两个文字。

建议位置为画面右上角 **X 1144、Y 64**（新装默认值），不会压住底部的人物信息条和左上 Logo。卡片会自动限制在画面内。早期版本把节目单放在右下角（如 X 1376、Y 912），换成票根卡后会与右侧人物条重叠，请在主控台把节目单拖到右上角或用「右上」快捷定位。

## 自动避让



- 让开时选移动距离最小、不出画面、并与其他模块留出 16 px 间距的位置：先试上下移动，放不下再左右移动，最后才斜向移动。
- 人物信息条例外：**不管谁先出现，都由人物信息条让开**，其他模块不动。它不会上下跳，而是保持在原来那一行，整组往没有障碍的一侧平移（障碍在右就往左靠，在左就往右靠），两条之间的距离保持不变，并和障碍留 96 px。整组平移会越过画面安全区（左右各 96 px，即预览里的虚线框）时，外侧那条停在安全区边上，再缩小两条之间的距离（至少 24 px）；还放不下，就把和障碍的距离逐步减到 48 px。这一行实在放不下时，才退回「后出现的让开」。
- 挡住人物信息条的模块关闭后，要等它的退场动画完全放完（时长按该模块的动画设置），人物信息条才滑回原来左右对称的位置；淡出途中重新打开，则保持靠拢不动。
- 避让只是画面上的临时偏移，不改写保存的位置。冲突消失（比如先出现的模块隐藏了）后，模块自动滑回原位，人物信息条恢复原来左右对称的样子。
- 尺寸按实际画面量取（节目卡高度随内容变化）。输出页与主控台预览用同一套计算，结果一致；移动时有约 0.35 秒的缓动，刚出现的模块直接出现在让开后的位置。
- 在主控台预览里拖动时，各模块保持当前位置不跳动，松手后再重新计算；OBS 输出在拖动过程中就会实时避让。
- 预览工具栏的「自动避让」可随时关闭，开关状态保存在 `settings.json` 的 `layout.autoAvoid`。
